# FocusDock for macOS

Public release assets and release notes for FocusDock.

## Beta status

The free beta is being prepared. There is no verified installer available in this repository yet. A download will appear here only after the macOS package has been built and checked.

When available, each release will include the supported macOS requirement and architecture, version and publication date, file size, release notes, installation and removal instructions, known issues, and the SHA-256 checksum for the DMG.

Camera compatibility depends on the camera and the controls its macOS driver exposes. The Logitech C920 shown in the product demonstration is an example, not a general compatibility certification.

FocusDock adjusts camera controls while video capture remains in the user's chosen app. It does not capture or process video frames and does not create a virtual camera.
